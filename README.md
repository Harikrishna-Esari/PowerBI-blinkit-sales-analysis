# 🛒 Blinkit Sales Analysis | Power BI Dashboard

## 📌 Project Overview  
This project presents an end-to-end analysis of Blinkit's sales performance, customer satisfaction, and inventory distribution using Power BI.  
The goal is to uncover actionable insights to optimize sales strategies and improve business performance.

---

## ❗ Business Problem  
Blinkit operates across multiple outlets with diverse product categories but lacks a centralized view to:
- Track overall sales performance  
- Understand customer preferences  
- Evaluate outlet efficiency  
- Optimize inventory distribution  

---

## 🎯 Objectives  
- Analyze total and average sales performance  
- Evaluate customer satisfaction through ratings  
- Understand product demand across categories  
- Compare outlet performance based on size, location, and type  
- Identify opportunities for business optimization  

---

## 📊 Dataset Description  
The dataset contains transactional and product-level data, including:
- Item Type & Fat Content  
- Outlet Type, Size, and Location  
- Sales Revenue  
- Customer Ratings  
- Establishment Year  

---

## 🧹 Data Cleaning & Transformation  
Performed using **Power Query**:
- Removed null and duplicate values  
- Standardized categorical fields  
- Fixed inconsistent data entries  
- Created calculated columns  
- Ensured correct data types  

---

## 📈 KPIs Explained  
- **Total Sales** → Overall revenue generated  
- **Average Sales** → Revenue per transaction  
- **Number of Items** → Total items sold  
- **Average Rating** → Customer satisfaction indicator  

---

## 📊 Dashboard Features  

### 1. Sales by Fat Content  
- Donut chart showing low-fat vs regular items  
- Helps understand customer preferences  

### 2. Sales by Item Type  
- Bar chart identifying top-performing categories  

### 3. Fat Content by Outlet  
- Stacked column chart comparing sales across outlets  

### 4. Sales by Outlet Establishment  
- Line chart showing sales trends over time  

### 5. Sales by Outlet Size  
- Pie/Donut chart comparing outlet sizes  

### 6. Sales by Location  
- Map showing geographic sales distribution  

### 7. Metrics by Outlet Type  
- Matrix view combining all KPIs  

---

## 🔍 Key Insights  
- Low-fat products contribute significantly to total sales  
- Certain item categories dominate revenue  
- Medium-sized outlets generate higher sales  
- Urban locations outperform others  
- Newer outlets show strong growth trends  
- Higher-rated products drive better sales
